# Privacy checklist before making this repository public

Search the entire repository and commit history for all of the following:

- real names and private nicknames
- email addresses and phone numbers
- usernames, group names and account IDs
- API keys, tokens, passwords and webhook secrets
- private domains, deployment URLs and database URLs
- home/work locations and default cities tied to a person
- health, cycle, sleep or wearable data
- relationship/persona prompts
- private household/pet names and world-building details
- private correspondence contacts
- personal diary, memories, summaries and chat excerpts
- MiniApp assets, CSS and layouts you do not want to license publicly
- tool implementations that expose private services or workflows

## Important

Do not sanitize a private repository by deleting sensitive files and then making
the same repository public. Git history can retain deleted content.

Create a new repository with a fresh commit history, as this repository does.
